# مشروع تطبيق "جنازة" (Janaza)

## نظرة عامة
تطبيق "جنازة" هو تطبيق مخصص لمدينة بلقاس في محافظة الدقهلية، يهدف إلى تسهيل عملية نشر إعلانات الوفيات وإيصالها بشكل فوري لجميع أهالي المدينة. يتيح التطبيق للمستخدمين إنشاء إعلانات تتضمن اسم المتوفى ومكان وموعد الجنازة ومكان وتوقيت العزاء وأي تفاصيل إضافية، ويقوم بإرسال إشعارات فورية لجميع مستخدمي التطبيق.

## هيكل المشروع
```
janaza-app/
├── janaza-mobile/           # تطبيق الهاتف المحمول (React Native/Expo)
│   ├── src/
│   │   ├── screens/         # شاشات التطبيق
│   │   ├── components/      # مكونات واجهة المستخدم
│   │   ├── services/        # خدمات التطبيق (المصادقة، الإعلانات، الإشعارات، الدفع)
│   │   ├── navigation/      # نظام التنقل بين الشاشات
│   │   ├── context/         # سياق التطبيق وإدارة الحالة
│   │   ├── utils/           # أدوات مساعدة
│   │   ├── config/          # ملفات التكوين
│   │   └── assets/          # الموارد (الصور، الخطوط، إلخ)
│   ├── App.js               # نقطة الدخول الرئيسية للتطبيق
│   └── app.json             # تكوين Expo
│
├── website/                 # الموقع التعريفي للتطبيق
│   ├── index.html           # صفحة الويب الرئيسية
│   ├── styles.css           # أنماط CSS
│   └── script.js            # سكريبت JavaScript
│
├── google_play_deployment_guide.md    # دليل نشر التطبيق على متجر Google Play
├── app_store_deployment_guide.md      # دليل نشر التطبيق على متجر App Store
├── user_guide.md                      # دليل المستخدم
└── README.md                          # ملف التوثيق الرئيسي (هذا الملف)
```

## المميزات الرئيسية
1. **نظام تسجيل المستخدمين**: تسجيل وإدارة حسابات المستخدمين.
2. **إنشاء إعلانات الوفاة**: إمكانية إنشاء إعلانات تتضمن كافة التفاصيل المطلوبة.
3. **نظام الدفع**: آلية آمنة لدفع رسوم نشر الإعلانات.
4. **نظام الإشعارات**: إرسال إشعارات فورية لجميع المستخدمين عند نشر إعلان جديد.
5. **عرض آخر الوفيات**: صفحة مخصصة لعرض آخر إعلانات الوفاة.
6. **واجهة مستخدم بسيطة واحترافية**: تصميم سهل الاستخدام بألوان (أسود، أصفر، أبيض، رمادي).

## التقنيات المستخدمة
- **تطوير التطبيق**: React Native / Expo
- **قاعدة البيانات**: Firebase Firestore
- **المصادقة**: Firebase Authentication
- **الإشعارات**: Expo Notifications
- **الموقع التعريفي**: HTML5, CSS3, JavaScript
- **التصميم المتجاوب**: CSS Flexbox & Grid

## متطلبات التشغيل
### لتطوير التطبيق:
- Node.js (v14 أو أحدث)
- npm أو yarn
- Expo CLI
- حساب Firebase
- Android Studio (لاختبار تطبيق Android)
- Xcode (لاختبار تطبيق iOS، يتطلب جهاز Mac)

### لتشغيل التطبيق:
- جهاز Android (الإصدار 5.0 أو أحدث)
- جهاز iOS (الإصدار 11.0 أو أحدث)

## بدء الاستخدام
### تثبيت التطبيق للتطوير:
1. استنساخ المستودع:
```bash
git clone https://github.com/yourusername/janaza-app.git
cd janaza-app/janaza-mobile
```

2. تثبيت الاعتماديات:
```bash
npm install
```

3. بدء خادم التطوير:
```bash
npm start
```

4. تشغيل التطبيق على جهاز محاكاة أو جهاز فعلي:
- اتبع التعليمات في نافذة الطرفية لتشغيل التطبيق على الجهاز المطلوب.

### تشغيل الموقع التعريفي محليًا:
1. انتقل إلى مجلد الموقع:
```bash
cd janaza-app/website
```

2. افتح ملف `index.html` في متصفح الويب.
